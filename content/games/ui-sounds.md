# UI sounds

Feedback effects, not vocabulary — `role | filename`, the same shape as a topic's
`## Sounds`. The role is fixed (the code looks it up); the file is yours to swap.

A role listed twice gives variants, picked at random per play, so a sound a child triggers
over and over does not read as a loop.

- tap | pop
- correct | bell_ring
- fanfare | crown_cheer_and_applaude
- fanfare | fireworks
